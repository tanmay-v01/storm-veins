# Storm Veins

React + TypeScript marketing site for Storm Veins.

## Run locally

```bash
npm install
npm run dev
```

The private studio lives at `/studio`. Set `VITE_STUDIO_PASSWORD` in `.env.local`; the demo fallback is `storm-ops`.

The studio gate is client-side convenience protection only. Replace it with a backend session/auth provider before using it for sensitive documents or payment data.
